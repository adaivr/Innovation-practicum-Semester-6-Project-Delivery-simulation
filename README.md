## Задача

## Описание
Одностраничный сайт с двумя областями:
1. Карта - отображает текущее положение заказов.
2. Таблица заказов - управляет заказами и симуляцией.

## Основные функции
 - Создание заказов
 - Управление текущей датой
 - Автоматическая симуляция
